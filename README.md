# Лабораторная работа №5
## Разработка базового SPA на React

### Цель работы
Разработка одностраничного приложения (SPA) на React с TypeScript, подключение к веб-сервису и реализация функционала просмотра услуг с фильтрацией.

---

### Задание

Разработать фронтенд-приложение на React с TypeScript, состоящее из трёх страниц:

1. **Главная страница** - статическое описание приложения
2. **Страница списка услуг** - с карточками услуг и фильтрами
3. **Страница просмотра услуги** - детальная информация об услуге

#### Требования к функциональности:

- **Навигация**:
  - Навигационная панель (navbar) для перехода между страницами
  - Самописная навигационная цепочка (breadcrumbs), отображающая путь от базовой страницы к текущей

- **Страница списка услуг**:
  - Фильтры с бэкенд-фильтрацией:
    - По диапазону дат
    - По названию
    - По цене
  - Карточки услуг с изображениями
  - Изображение по умолчанию, если поле изображения пустое

- **Технические требования**:
  - Использование React-Bootstrap компонентов
  - Самостоятельная реализация AJAX-запросов через fetch
  - Решение CORS через проксирование React
  - Резервный механизм с mock-данными при недоступности бэкенда
  - Без использования Redux и Context API

---

### Порядок демонстрации

1. **Фронтенд с mock-данными**:
   - Показать три страницы приложения без запущенного серверного сервиса
   - Продемонстрировать работу с mock-объектами

2. **Фронтенд с бэкендом**:
   - Запустить веб-сервис и показать работу приложения с реальными данными
   - В Network показать адрес fetch-запросов через proxy
   - Показать названия и адреса изображений из MinIO

3. **Взаимодействие с БД**:
   - Внести изменения в базу данных через бэкенд
   - Показать отражение этих изменений во фронтенде

4. **Объяснение кода**:
   - Показать и объяснить код компонентов для фильтрации
   - Объяснить передаваемые props
   - Продемонстрировать использование хуков
   - Показать вызовы fetch и обработку данных

### Техническая реализация

- **Стек технологий**: React, TypeScript, React-Bootstrap
- **Запросы к API**: нативный fetch с обработкой ошибок
- **Проксирование**: настройка proxy в React для обхода CORS
- **Резервные данные**: fallback на mock-данные при недоступности API
- **Компоненты**: функциональные компоненты с хуками
- **Навигация**: React Router для маршрутизации
